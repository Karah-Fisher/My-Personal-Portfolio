# My Responsive HTML & CSS Portfolio

This is a clean, multi-page personal portfolio website built to showcase my transition from education into technology, my current skills, and my journey toward becoming a full-stack developer.

## Project Overview

This project marks the beginning of my professional technical portfolio. It serves as a central hub to display my web development skills, coding academy projects, and career goals. 

### Core Features Included:
*   **Home Page**: Features a responsive hero section, a personal summary, and a strong Call-to-Action button.
*   **About Page**: Shares my journey from working as a teacher's assistant to pursuing my passion for coding, alongside structured learning goals.
*   **Projects Page**: Uses a semantic table to track completed and upcoming learning roadmap objectives.
*   **Contact Page**: Contains a fully styled user input form with proper accessible labeling.

---

## Built With

*   **HTML5** - Semantic markup structure (headers, main, sections, tables, forms).
*   **CSS3** - Custom styling, global resets, and typography.
*   **Flexbox** - Responsive layout alignment for the navigation and hero sections.

## How to Run the Project Locally

To view this website on your local machine:

1. **Clone or download** this repository to your computer.
2. Navigate into the `html-css-portfolio` directory.
3. Double-click the `index.html` file to open it automatically in any web browser.
4. *(Optional)* If using VS Code, right-click `index.html` and select **"Open with Live Server"** for real-time updates.
